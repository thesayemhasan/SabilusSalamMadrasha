# সাবিলুস সালাম মাদরাসা ও মহিলা মাদরাসা, ঢাকা — ওয়েবসাইট ও ম্যানেজমেন্ট সিস্টেম

ধাপ ১: পাবলিক ওয়েবসাইট (বাংলা/আরবি/ইংরেজি) + অ্যাডমিন প্যানেল।
প্রযুক্তি: React + Vite (ফ্রন্টএন্ড), Supabase (ডাটাবেস, লগইন, ছবি)।

## ১. Supabase সেটআপ (একবার)

1. supabase.com এ প্রজেক্ট খুলুন।
2. **SQL Editor** এ `supabase/schema.sql` ফাইলের পুরোটা পেস্ট করে **Run** চাপুন।
3. **Authentication → Users → Add user** এ নিজের ইমেইল ও পাসওয়ার্ড দিয়ে প্রথম ব্যবহারকারী তৈরি করুন (Auto confirm চালু রাখুন)।
   প্রথম ব্যবহারকারী নিজে থেকে **সুপার অ্যাডমিন** হয়ে যাবে।
4. **Authentication → Sign In / Providers** এ গিয়ে "Allow new users to sign up" বন্ধ করে দিন, যাতে বাইরের কেউ অ্যাকাউন্ট খুলতে না পারে।
5. **Project Settings → API** থেকে `Project URL` ও `anon public key` কপি করুন।

## ২. নিজের কম্পিউটারে চালানো

```
cp .env.example .env      # .env তে URL ও key বসান
npm install
npm run dev
```

## ৩. GitHub Pages এ চালানো

1. রিপোজিটরিতে সব ফাইল আপলোড করুন (branch: `main`)।
   `_gitignore`/`_env.example` নামের ফাইল থাকলে নাম বদলে `.gitignore` ও `.env.example` করুন।
2. **Settings → Secrets and variables → Actions** এ দুটি Secret যোগ করুন:
   `VITE_SUPABASE_URL` এবং `VITE_SUPABASE_ANON_KEY`।
3. **Settings → Pages → Source** এ **GitHub Actions** বেছে নিন।
4. `main` এ push করলে নিজে থেকে বিল্ড হয়ে সাইট চালু হবে।

অ্যাডমিন প্যানেলের ঠিকানা: `আপনার-সাইট/#/admin`

## ৪. নিজের ডোমেইন/হোস্টিংয়ে (cPanel)

1. `npm run build` চালালে `dist` ফোল্ডার তৈরি হবে।
2. `dist` এর ভেতরের সব ফাইল `public_html` এ আপলোড করুন। অন্য কিছু লাগবে না।

## ৫. অ্যাডমিন প্যানেল থেকে যা বদলানো যায়

- **সাইটের লেখা:** প্রতিটি লেখা তিন ভাষায় (নাম, ঠিকানা, মেনু, বাটন, ফরমের লেবেল সহ)।
- **নোটিশ, ইভেন্ট, গ্যালারি, শিক্ষকবৃন্দ:** যোগ/সম্পাদনা/মুছা/প্রকাশ-অপ্রকাশ।
- **প্রতিষ্ঠানের তথ্য ও থিম:** লোগো, ব্যানার, ফোন, ইমেইল, মানচিত্র, রং।
- **ভর্তির আবেদন ও যোগাযোগের বার্তা:** দেখা, অবস্থা বদলানো।
- **মডিউল সুইচ:** সব মডিউল অন/অফ।
- **মেশিন ও বাইরের সেবা:** ZKTeco, এসএমএস, পেমেন্টের তথ্য রাখার জায়গা।
- **ব্যবহারকারী ও অনুমতি:** ভূমিকা ঠিক করা।

## ৬. ডেভেলপারের জন্য নোট

- রাউটিং `HashRouter` (`/#/admin`), তাই সাবফোল্ডার ও cPanel এ রিফ্রেশে সমস্যা হয় না।
- নিরাপত্তা Supabase RLS দিয়ে: সবাই শুধু প্রকাশিত কনটেন্ট পড়তে পারে; লেখা/বদলানো শুধু `admin`/`super_admin`; আবেদন ও বার্তা বাইরে থেকে শুধু জমা দেওয়া যায়।
- `integrations` টেবিলের তথ্য (API key ইত্যাদি) শুধু অ্যাডমিন পড়তে পারে। বাস্তব এসএমএস/পেমেন্ট/মেশিন সংযোগ ক্লায়েন্টে নয়, Supabase Edge Functions বা আলাদা সার্ভারে করতে হবে (ধাপ ২ ও ৫ এ)।
- সব লেখার তালিকা `src/lib/texts.js` এ, মডিউল তালিকা `src/lib/modules.js` এ।

## ৭. পরের ধাপ

২. ছাত্র, শিক্ষক ও হাজিরা · ৩. বেতন, চাঁদা ও হিসাব · ৪. পরীক্ষা, হিফজ ও প্রিন্ট · ৫. এসএমএস, পোর্টাল, প্রমোশন ও বাকি মডিউল

## ফাইনাল ডিজাইন আপডেট (ধাপ ১ সমাপ্ত)
1. Supabase → SQL Editor এ নতুন `supabase/schema.sql` আবার পুরোটা Run করুন (আবার চালালে আগের ডাটা নষ্ট হয় না)।
2. GitHub রিপোজিটরিতে `src`, `index.html`, `supabase`, `README.md` ফোল্ডার/ফাইল নতুনগুলো দিয়ে বদলে দিন; Actions নিজে থেকে ডিপ্লয় করবে।
3. অ্যাডমিন → সেটিংস থেকে ডেভেলপারের নাম/ছবি/সোশ্যাল, হেডারের লেখা, মেনু, স্লাইডের উৎস ঠিক করুন।
4. ভর্তির কাগজপত্র (ছবি/জন্মসনদ) ব্যক্তিগত বাকেটে থাকে; শুধু অ্যাডমিন দেখতে পারেন।
5. সাইন আপ বন্ধ রাখতে: অ্যাডমিন → সেটিংস → "অ্যাকাউন্ট ও ভর্তি"।

## ধাপ ২ আপডেট: ছাত্র, শ্রেণি, শিক্ষক-কর্মচারী, হাজিরা

1. Supabase > SQL Editor এ নতুন `supabase/schema.sql` পুরোটা আবার Run করুন (আগের ডেটা নষ্ট হবে না)।
2. GitHub এ `src`, `supabase`, `README.md` বদলে দিন; Actions নিজে ডিপ্লয় করবে।
3. অ্যাডমিন প্যানেলে নতুন গ্রুপ "ছাত্র ও হাজিরা": ছাত্র-ছাত্রী, শ্রেণি ও হালকা, শিক্ষক ও কর্মচারী, হাজিরা, আবাসিক/অনাবাসিক ধরন, হাজিরার সময়।
4. ভর্তির আবেদন থেকে "ছাত্র হিসেবে ভর্তি করুন" বাটনে এক ক্লিকে ছাত্র তালিকায় যায়।
5. ZKTeco: "মেশিন ও বাইরের সেবা" এ চালু করে পুশ সার্ভার কী দিন; ছাত্র/কর্মচারীর ফর্মে মেশিনের আইডি দিন। সংযোগের তথ্য হাজিরা > মেশিন ট্যাবে আছে (ডেভেলপারের জন্য)।
6. ছাত্র/স্টাফ/হাজিরা মডিউল "মডিউল সুইচ" থেকে বন্ধ করলে মেনু ও পেইজ লুকিয়ে যায়।

## ধাপ ৩ আপডেট: ফি, রসিদ, আয়-ব্যয়, বেতন, রিপোর্ট, চার্ট

1. Supabase > SQL Editor (Database মোডে) নতুন `supabase/schema.sql` পুরোটা Run করুন।
2. GitHub এ `src`, `supabase`, `README.md` বদলে দিন।
3. অ্যাডমিন মেনুতে নতুন গ্রুপ "ফি ও হিসাব"। প্রথমে করুন: "ফি-র ধরন ও পরিমাণ" (পরিমাণ), "খাত ও পেমেন্ট মাধ্যম" (শুরুর জমা), "শিক্ষক ও কর্মচারী" (বেতন)। তারপর "বিল তৈরি" থেকে মাসের বিল, "ফি আদায় ও রসিদ" থেকে আদায়।
4. আদায়, আয়-ব্যয় ও বেতনের এন্ট্রি মোছা যায় না; ভুল হলে "বাতিল" (কারণসহ)। সব কিছু "আর্থিক লগ" এ জমা হয়।
5. হিসাবরক্ষক: ব্যবহারকারী পেইজে ভূমিকা "হিসাবরক্ষক" দিলে সে শুধু ফি ও হিসাব অংশ দেখতে পারবে।
6. ড্যাশবোর্ডে ছাত্র ও অর্থনৈতিক চার্ট, ওয়েবসাইট দেখার বাটন ও শর্টকাট আছে।
